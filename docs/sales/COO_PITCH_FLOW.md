# Venti WMS — COO First Meeting Flow

**Audience:** COO / Plant Head / VP Operations (Daikin, Voltas-class HVAC)  
**Duration:** 20 minutes · **12 slides main path** · 5 min Q&A · appendix on request  
**Goal:** Leave the room able to repeat: *"Offline floor, summer stock protected, capital visible, live in weeks."*

**Do not use in this meeting:** 3D twin walkthrough, AGV simulation, workflow builder, architecture diagrams, vision roadmap, full module catalog.

---

## Primary wedge (say this verbatim in the first 60 seconds)

> **Venti is offline-safe, operator-friendly warehouse execution for Indian HVAC plants — with measured savings and a live working-capital view in weeks, not years.**

**COO one-liner to repeat:**

> *"Cut picker travel, protect summer stock, free trapped capital — on tablets that work when the network doesn't."*
